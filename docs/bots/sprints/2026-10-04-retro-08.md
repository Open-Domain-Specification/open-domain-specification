## Corrections made during the work

- **Accessible name.** The tree control's icon glyph (a private-use codepoint) leaked into its accessible name, so an exact-name lookup for "Workspace tree" failed. An early proposal to strip the glyph inside the judging code would have hidden the product defect; the exact-name normalisation was rejected. The fix is a local `aria-hidden` on the decorative icon, and the exact raw browser name with a role count of 1 was then proven, collapsed and open.
- **Early reveal with a 4 px clip.** Widening from the narrow scroller to desktop revealed the current row too early under reduced motion. The cause was the layout transition, which settles after the query change; reduced motion pads transitions to 0.01 ms, so a plain after-tick reveal was too early. The old row bottom was 904 against a scroller of 900 (earlier scroll 784 where 788 was needed, a 4 px clip). The fix awaits the actual owned nav animations to finish, then reveals only if still wide. It uses no sleep and no pixel fudge.
- **Modifier clicks.** Modified or non-primary clicks on tree anchors collapsed the tree though the router ignores them. A guard now closes only on an activation the router takes; five unit reds then went green.
- **Synthetic anchor test.** A queued synthetic anchor click's default action was not prevented, and this leaked into an embedded test. Moving the describe block did not resolve it; that only masked it. The cause was traced to the default action of the cancelled synthetic anchor, and the final fixture captures the app's claim flag before cancelling the click, which passes in both describe orders.

The controls were:

- Exactly two observed product findings, local source ownership, no global Icon or speculative change.
- One actual cause probe, and at most two unsuccessful corrections of the same class before reassessing through the coordinator.
- Exact browser accessible-name lookup, with both motion preferences asserted explicitly. Unit behaviour alone cannot approve layout.

These controls held for the correction. They were broken beforehand by the judge corrections, the captures and the third probe, and nothing in the evidence shows the controls would prevent every such overrun. This is not a claim of a proven universal cause.
