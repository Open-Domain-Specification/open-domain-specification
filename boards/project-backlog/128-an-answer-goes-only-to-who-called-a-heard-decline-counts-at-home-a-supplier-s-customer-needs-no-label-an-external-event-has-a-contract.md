# An answer goes only to who called; a heard decline counts at home; a supplier's customer needs no label; an external event has a contract

The architect's thirteenth round found a defect card 126 introduced and three smaller things. `routesTo`'s fourth clause, the single-operation inference, returns the sole operation as the route for any reactor in the context without checking that the reactor issues it, so with `by` absent a bystander policy that names the answer hears it, the flow map draws it, and a policy issuing the front on the bystander's event closes a phantom `reaction-cycle`; with `by` written the same shape is refused. Decisions 21 and 23 say the inference behaves as `by: [thatOperation]` would. `rejection-raised`'s `heardElsewhere` counts only other contexts' consumers, so a decline the raising context's own dunning policy reacts to still warns, and decision 25's note says somebody hearing it is enough. `role-coherence` asks a customer-supplier downstream that uses the negotiated interface with no translation to call itself a conformist, which in Evans means the opposite. And an external context can state a contract on its own operation but not on the payload of an event it publishes, though the amendment's own argument, a published contract is citable, applies word for word to a webhook payload. Decisions 03, 21, 25 and 28 are amended.
