# Evidence opens and closes from the keyboard

Issue #48, a child of epic #61 (accessible navigation across the viewer, export and extension). The badges on a context map disclose a relationship's evidence. They were already `<button>`s that opened a card on click, and Escape already closed it, but nothing said that a badge held more, the card was not a dialog, focus stayed behind on the badge (so the next Tab went to whatever followed the badge in the page rather than into the card), and closing the card left focus nowhere. A badge now names what it shows, announces a dialog, reads as expanded and controlling the card while open; the card is a named dialog that takes focus on open; Escape and the card's Close button return focus to the badge that opened it. Hover, click and click-elsewhere are unchanged. The same bundle runs in the webview, the viewer and the static export; the real VS Code host is the lead's integration pass.

- **developer** (2026-09-29T21:34:13.000Z): Mechanism: one dismissal stack, `src/lib/layers.ts`. A layer calls `openLayer({ dismiss })` when it opens and the returned function when it closes; a single `window` capture listener, bound only while the stack is not empty, closes the top entry and calls `stopPropagation`. Fullscreen (`fullscreen.svelte.ts`), the evidence card (`disclosure.svelte.ts`), the pattern explanation (`hover.svelte.ts`) and the Modal (`Modal.svelte`) all register; none listens for Escape itself any more. Why a stack over each layer stopping the key on its own element: the layers are not nested in the DOM (the card is in a viewport portal, an explanation is a child of a keyword, the Modal's panel is a sibling of the page), so "nearest to focus wins" is wrong whenever focus is on a trigger and the layer that should close is not its ancestor, and the phase tricks were what broke. The stack is in opening order, which is inside-out because a layer is opened from inside the one below it. Each layer's `dismiss` does its own focus: the card returns to its badge, the Modal keeps its own return-to-trigger effect on `showing`, an explanation leaves focus on its keyword, fullscreen leaves it where it is. Modal conventions (card 43) are unchanged: the focus trap and return are as they were; only its Escape branch moved from the panel's `keydown` into the stack.
