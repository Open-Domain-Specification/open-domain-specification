# Svelte Flow diagrams replace the static Graphviz figures

Every figure on the pages is now the interactive Svelte Flow diagram; the static Graphviz SVG, its lightbox and the static/interactive toggle go. The pages package stops rendering DOT: `DiagramFigure` takes only a graph, `Model.renderDot` and `dotToSvg` are removed with the wasm dependency. The `@open-domain-specification/graphviz` package stays as a library (the flow adapters import its role labels). Follows boards/project-backlog/31-context-sketch-and-uml-diagrams.md.
