# Nested schema users are shown instead of marking the shape unused

Issue #114. The lead found eight reference-model schemas with no direct consumable carrier that another schema nests: RiverMart `SearchHit`, `OrderLine`, `ReturnLine`, `SponsoredSlot` and `PurchaseOrderLine`; StreamLine `HomepageRow` and `AdSlot`; NorthBank Ledger `PostingLine`. The context page in the VS Code webview, the viewer and the static export called them "unused", and Markdown's "Used by" column printed `-`, because both read `DataSchema.consumables`, which lists carriers only. The third signoff round found the same omission for an identity-only use: RiverMart `Capture.providerPaymentId` identifies the external `ProviderPayment` schema, which the broad lists still called unused. This card covers both cases. The nested-only case was the lead's pre-review finding; the identity case was reproduced independently by Astra and Opus.
