# Nested schema users are shown instead of marking the shape unused

Issue #114. The lead found eight reference-model schemas with no direct consumable carrier that another schema nests: RiverMart `SearchHit`, `OrderLine`, `ReturnLine`, `SponsoredSlot` and `PurchaseOrderLine`; StreamLine `HomepageRow` and `AdSlot`; NorthBank Ledger `PostingLine`. The context page in the VS Code webview, the viewer and the static export called them "unused", and Markdown's "Used by" column printed `-`, because both read `DataSchema.consumables`, which lists carriers only. This card is the fix; it is a pre-review finding by the lead, not a reviewer verdict.
