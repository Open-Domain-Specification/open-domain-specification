# The reader knows where they are

Issue #50, a child of epic #61. The tree marked the page being read with a background wash and nothing else, so a screen-reader reader could not tell which row was the current page, and the tree and the table of contents were not distinguishable landmarks (the contents was an `aside`). The tree row for the page being read now carries `aria-current`, decided in one place with the wash so the two cannot disagree, and the tree, the page and the contents are each a landmark, the two navigations told apart by name. The tree is drawn in the viewer and the static export; the VS Code webview has the page and the contents and no tree, because the extension's own tree view is its navigation.

- **developer** (2026-09-29T21:24:00.000Z): Correction, after the owner's review of PR #76. The earlier entries above that put `aria-current="true"` on the ancestor rows, and the decision that the accessible state must equal the drawn wash, were wrong. `aria-current="true"` means "the current item", not "an ancestor of the current page", and WAI-ARIA recommends marking one item in a related set as current; giving the context and its aggregate both a current value told a screen-reader reader two rows were the current item. The rule now: only the page's own row carries `aria-current="page"`; ancestors are highlighted by the wash only and carry none; a page with no tree row marks nothing. The two facts are separate in `packages/pages/src/lib/organisms/Sidebar.svelte:54-77` (`onTheWay` draws the wash, `here` picks the one current link), `Ref` and `Lockup` take `current?: "page"` only, the Sidebar unit tests and `packages/pages/e2e/current-page-landmarks.spec.ts` assert exactly one `aria-current` link with the ancestors still `.item.active`, on the viewer and the export, through Enter, back and forward, and `docs/design/design-language-v2.md` and `STATUS.md` say the same. The real-host journey (`apps/ods-vscode/e2e-keyboard/journeys.spec.ts`) asserts only that the webview has no tree row current, so it needed no change.
