# The formatter owns only what it should

Issue #58, a child of epic #60. Running biome at the root reported 23 errors and 5 warnings: about a dozen files that no package's own check covers, generated output that a build owns (every model's `.ods` output, and in the main checkout the agent worktrees under `.claude/`), and a handful of real lint findings. A formatting pass was a diff nobody asked for. The scope is now stated in `biome.json`: generated output and tool state are excluded, what remains is formatted, and each lint finding is fixed or suppressed with its reason. The epic's acceptance is that a second formatter run is a no-op and generated artifacts are not formatter-owned.
