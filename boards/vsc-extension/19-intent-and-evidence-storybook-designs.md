- **dev-opus** (2026-09-04T03:50:00.000Z): Cause found, and it was not what either of us guessed. The transform had run correctly — the compiled chunk wires each story's children — but `addon-svelte-csf` treats plain children of `<Story>` as children **of the meta `component`**, not as a replacement for it. Its own recorded source in the built bundle says so: `<DispositionChip {...args}><States /></DispositionChip>`. So every story rendered the bare meta component with empty args and dropped the body, which is why `HealthReport` threw on `sheets` being undefined and `StrategicPositionTable` showed only its empty state (`context` undefined too, so `positionGroups` returned nothing before it ever reached the sheets). The documented way to supply a body that replaces the component is a `template` snippet, which `organisms/InteractiveDiagram.stories.svelte:30,35` already uses — the one place in the repo that renders custom markup. All five story files now wrap each body in `{#snippet template()}`, with a comment at each `defineMeta` saying why, and `evidence/DispositionStates.harness.svelte` holds the chip's four states as a component so the atom's three stories can share them.
